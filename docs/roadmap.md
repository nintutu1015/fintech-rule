## v0.2：自己的服务规则

- [x] 从 AI、PayPal、Bybit、英国运营商四类开始逐项整理，见 [服务清单](services.md)。

- [ ] 在 Loon 请求日志里逐类确认，并在服务清单填写设备验证日期。
- [ ] 补充你的其它常用 App / 网站（先给域名和想要的出口）。
- 对 A_Global 覆盖具体服务的情况逐项决定，不一次性改掉所有顺序。
- 明确的自有规则可逐步发布为可订阅的单策略文件；先确认来源优先级变化。

## v0.3：上游变化与回退

- 保存带日期和哈希的上游审查快照；先核对各来源许可与更新方式。
- 比较新增、删除和策略重叠，形成可审阅的变更，不直接覆盖配置。
- 建立设备验证记录和发布标签。
- 有稳定的手动流程后，再决定是否需要定期自动检查。
